# 🏨 Palace Lodge Website

Palace Lodge is a web-based Booking Management System developed using ASP.NET, C#, and SQL Server to streamline lodge operations and improve booking efficiency. The system prevents double bookings, manages room availability, customer reservations, and housekeeping assignments. It also incorporates booking modifications, cancellation management, overbooking controls, and management reports to support informed decision-making. Designed with a focus on automation, data accuracy, and operational efficiency, the system provides a centralised solution for managing daily lodge activities.
